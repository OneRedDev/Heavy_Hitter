# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-07
### Added
- Initial release of Heavy Hitter.
- Multithreaded UDP flood capability.
- Atomic counter for packet tracking.
- Signal handling for clean exit (`Ctrl+C`).
- Makefile for easy compilation.
- MIT License.
- Contributing guidelines.

### Changed
- Renamed executable from `udp_flood` to `heavy_hitter`.

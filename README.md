# 🚀 Heavy Hitter v1.0

A multithreaded UDP flood tool designed to saturate network devices.

## ⚠️ Note: Make sure you edit the `TARGET_IP` in the code before compiling!

## How to Use
To use, install a C compiler for your platform (e.g., `gcc` on Linux/WSL via `sudo apt install gcc`,
MinGW on Windows, or `pkg install gcc` in Termux on Android), then compile with `gcc -o heavy_hitter heavy_hitter.c -lpthread` and execute the resulting binary (`./heavy_hitter` or `heavy_hitter.exe`) to begin the attack.

## Make sure to change IP,Ports and Threads before running the code!

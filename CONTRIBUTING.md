# Contributing to RedCore Heavy Hitter

## How to Contribute

1.  **Fork** the repository.
2.  **Clone** your fork locally.
3.  Create a new branch for your feature or bugfix:
    ```bash
    git checkout -b feature/your-feature-name
    ```
4.  Make your changes. Ensure the code compiles with `make`.
5.  Commit your changes:
    ```bash
    git commit -m "Add: description of change"
    ```
6.  Push to your branch:
    ```bash
    git push origin feature/your-feature-name
    ```
7.  Open a **Pull Request**.

## Guidelines

*   Keep the code clean and efficient.
*   Do not break the existing functionality.
*   Follow the coding style of the original author.
